01
HCIWireframeUX

HAU Dorm Finder

A front-end-only prototype built for a Human-Computer Interaction project, helping students search for housing near campus.

Read the write-up +

Built as five linked HTML pages plus a shared stylesheet, kept deliberately in strict low-fidelity wireframe style—greyscale boxes and placeholder labels instead of finished visuals. The exercise was about the structure and flow: how someone moves from search to a listing, then to details, and where the friction points are. Good UX begins before a single color is chosen.

MonsterMatch — Love at First Bite

A dating-app-style profile card built for Intro to Web Design, demonstrating card styling, tables, forms, and CSS transitions.

Read the write-up +

The brief was to demonstrate CSS card styling, HTML tables and forms, and transition work in one cohesive piece—so it became a playful monster dating profile. I went through a few design passes to land on a red and dark-maroon palette and a circular-cropped profile image before the hover states felt right. It’s the project where CSS transitions really clicked.

03
ResponsiveCSSFlexbox

Curbside Thai

A food-truck business site rebuilt to be fully responsive, using a CSS-only rewrite rather than restructuring the markup.

Read the write-up +

Starting from an existing, non-responsive site, I made it work at every screen size using only CSS—no HTML restructuring. I set breakpoints at 900px and 600px and rebuilt the layout with Flexbox so the menu, hero, and contact sections reflow instead of simply shrinking. The constraint made it a great exercise in how far layout alone can go.

Iris Music Player

A browser-based music player inspired by “Iris” by Goo Goo Dolls, bringing lyrics, media, and a simple configuration file together in one page.

Read the write-up +

This project explores how HTML, CSS, and JavaScript can work together to create a music-focused browser experience. The page brings together media controls, synchronized lyrics, and a small student.json configuration file. It is a chance to practice building a more interactive interface while keeping the design focused on one song.
